## Contexto para ler: context/project/design/exports/desktop.html (Login, Registro — Criar conta, Esqueci a senha) e mobile.html (Login — Mobile, Registro — Mobile, Esqueci a senha — Mobile)
## Skills a carregar: codegen.md + frontend.md + security.md
## O que já existe: feature auth (4 ViewModels + 4 Views + auth-api) e API /api/auth/*
## O que criar:
- Rota `(auth)/layout.tsx` com SiteHeader + SiteFooter
- Páginas que montam as Views existentes (login, register, forgot-password, reset-password), ajustadas ao design:
  - **Login**: card com título/sub, campos com erro inline, botão, "Esqueci minha senha", divider, "Criar conta", painel lateral de benefícios (desktop) / sem painel (mobile)
  - **Registro**: Nome/Email/Senha, termos, "Criar conta"/"Já tenho conta"
  - **Esqueci a senha**: card centralizado, Email, "Enviar link", "Voltar para o login"
  - **Reset**: nova senha + confirmação
- Ajustar as Views existentes ao design system (task 09) — sem quebrar os ViewModels
## Especificação:
- **MVVM estrito**: View só JSX (recebe props do ViewModel); ViewModel orquestra (useMutation, estados loading/erro/sucesso)
- Estados: loading no submit, erro inline (borda vermelha + mensagem), sucesso
- Responsivo: card full-width no mobile, layout 2 colunas no desktop
- Sem expor dados sensíveis; feedback genérico em forgot (anti-enumeração)
## Critério de conclusão:
- [ ] 4 páginas de auth fiéis ao design (desktop + mobile)
- [ ] Fluxos integrados às APIs existentes (register/login/forgot/reset)
- [ ] Estados de erro/loading visíveis
- [ ] Barrel export atualizado
- [ ] Typecheck passando: `pnpm turbo typecheck --filter=@digimon/app-web`
- [ ] Lint passando
