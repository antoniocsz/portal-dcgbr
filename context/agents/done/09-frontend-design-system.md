- **Design tokens** em `globals.css` (@theme do Tailwind v4), mapeando o design system Digimon do `dcg.pen`:
  - Cores: `bg #0C0C0E`, `surface #16161A`, `surface-2 #202024`, `ink #F3F1EE`, `ink-soft #B5B3AE`, `ink-faint #8A8890`, `border #292930`, `primary #C22B33`, `primary-soft #331519`, `accent #6FA0A8`, `accent-soft #1A2A2E`, `success #3EB575`, `warning #E0A33D`, `danger #E5484D`

- **Componentes compartilhados** (apps/web/src/components/), fiéis ao design (View pura, sem hooks de dados):
  - `site-header.tsx` (desktop: logo + nav + busca + Entrar/Criar conta; mobile: logo + busca + hamburger) — reusa a nav ativa com underline
  - `site-footer.tsx` (colunas + strip de 7 cores)
  - `ui/button.tsx` (variantes: primary/ghost/dark), `ui/tag.tsx`, `ui/status-badge.tsx` (dot + label), `ui/color-chip.tsx`, `ui/avatar.tsx`, `ui/card.tsx`, `ui/metric-card.tsx`
  - `ui/color-strip.tsx` (faixa de 7 cores do header/footer)
  - `admin/admin-sidebar.tsx` (desktop) + `admin/admin-nav.tsx` (mobile: chips)
  - `post-card.tsx`, `card-tile.tsx`, `deck-card.tsx`, `tournament-card.tsx`, `comment-row.tsx`
- Integrar `site-header`/`site-footer` no `layout.tsx` (rotas públicas) — painel admin usa layout próprio
## Especificação:
- **MVVM estrito**: componentes em `components/` são Views puras (só JSX + props); sem useQuery/useMutation/useForm
- Tailwind v4 (`@theme` no CSS) — sem tailwind.config.js
- Dark theme como padrão do portal (o design é dark-only)
- Ícones via `lucide-react` (mesma biblioteca do design)
- Nomes/estrutura seguem o `dcg.pen` (data-pencil-name → nomes de componentes)
- Mobile-first: usar breakpoints do Tailwind (md:, lg:) para alternar desktop/mobile
